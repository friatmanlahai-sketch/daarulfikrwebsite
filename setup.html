Penyiapan Firebase

Panduan singkat untuk pengelola. Panduan lengkap ada di file PANDUAN-ONLINE.md.

Periksa koneksi

Tekan tombol di bawah. Hasil hijau berarti bagian itu sudah siap. Hasil merah menjelaskan apa yang perlu diperbaiki.

    Langkah penyiapan

    1. Firebase Console → Build → Firestore Database → Create database (mode production).
    2. Authentication → Sign-in method → aktifkan Email/Password.
    3. Authentication → Users → Add user: buat akun admin (email dan password kuat).
    4. Buka firestore.rules, ganti GANTI-DENGAN-EMAIL-ADMIN@gmail.com dengan email admin tadi, lalu Publish di tab Rules (atau firebase deploy).
    5. Authentication → Settings → Authorized domains → pastikan domain situs Anda ada di daftar.
    6. Login di admin.html → menu Alat → Isi data awal.
